# DeFi Liquidity Pool Simulation

> 去中心化金融（DeFi）流动性池仿真与决策优化 | 决策仿真课程实践 · 案例 21

**Status: Planning · 项目初始化阶段。** 本仓库用于逐步存放 Arena 仿真模型、Python 数据处理与分析脚本、建模文档和实验结果。当前尚未发布可运行模型或经验证的实验结论。

## 项目简介

以去中心化交易所（DEX）的自动化做市商（AMM）流动性池为研究对象，基于恒定乘积模型，模拟用户代币兑换（Swap）、流动性提供者添加与移除流动性（Mint/Burn）、市场价格变化及其对交易体验和 LP 收益的影响。课程基础案例采用 **7 天（168 小时）** 的仿真周期。

项目目标是：建立可检查的基准仿真，在此基础上比较交易费率、流动性撤出及外部市场波动等情景，并评估手续费收入、滑点、交易完成情况与无常损失。

## 课程案例基准设定

下表是课程材料给定的**假设情景参数**，不是已采集到的真实链上观测数据。

| 参数 | 基准设定 |
| --- | --- |
| 代币储备 | Token A：1,000,000；Token B：2,000,000 |
| 初始价格 | 1 A = 2 B |
| Swap 到达间隔 | EXPO(5) min |
| 小/中/大额交易占比 | 60% / 30% / 10% |
| 交易规模（以 A 为单位） | 100–1,000 / 1,000–10,000 / 10,000–50,000 |
| 对应滑点容忍度 | 1% / 3% / 5% |
| 基准交易手续费率 | 0.3% |
| LP 添加流动性间隔 | EXPO(2) h |
| LP 移除流动性间隔 | EXPO(3) h |
| 外部价格变化率 | 每小时 NORM(0%, 2%) |
| 仿真时长 | 168 h（7 天） |
| 计划重复次数 | 10 次 |

以上模型将按需明确随机分布、单位与模型简化条件，避免把课程假设误写为协议真实参数。

## 模型与指标（待实现）

- **AMM**：恒定乘积 `x × y = k`。有手续费时，Swap 的有效输入需扣除手续费；实际储备与 `k` 的变化应按一致口径更新，不把每次交易后的 `k` 错写为恒定不变。
- **事件**：Swap、Mint、Burn、外部价格更新；维护事件先后顺序及池中两种代币的状态。
- **交易体验**：交易量、执行价格、价格影响/滑点、超过容忍阈值的交易比例。
- **LP 表现**：手续费收入、LP 份额与持仓价值；在明确的基准条件下，与直接持有相同初始资产比较以衡量无常损失。
- **运营表现**：储备轨迹、池内价格与外部参考价格、不同情景下的指标分布。

## 技术路线（计划）

1. 整理课程规则、指标口径与参数表。
2. 使用 **Arena** 建立离散事件仿真流程，跟踪 Swap / Mint / Burn 与池状态。
3. 使用 **Python** 辅助校验 AMM 公式、数据处理、结果分析和绘图。
4. 进行基准校验、多次重复仿真、情景对比和敏感性分析。
5. 如扩展到真实数据，先确定交易池、数据窗口、事件字段及采集方式，再实现数据回放。
